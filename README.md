# Fruit Station Data — Painel de calculadoras

Projeto estático preparado para **GitHub Pages**.

## Páginas

- `index.html`: tela inicial (aberta automaticamente pelo GitHub Pages)
- `misturador.html`: calculadora do misturador
- `dosys.html`: calculadora da bomba Dosys
- `helicoidal.html`: calculadora da bomba helicoidal

CSS, JavaScript e imagens permanecem em arquivos locais. A exportação de PDF usa jsPDF de uma CDN e as fontes usam Google Fonts, exigindo internet para esses recursos.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub (público ou elegível para Pages no seu plano).
2. Envie **o conteúdo desta pasta** para a raiz do repositório, com o `index.html` na raiz.
3. Vá em **Settings → Pages → Build and deployment**, selecione **Deploy from a branch**, branch **main** e pasta **/(root)**. Salve.
4. Acesse `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Execução local

Abra `index.html` no navegador. Não é necessário backend ou compilação.

## Observação

O GitHub Pages é hospedagem pública de arquivos estáticos. Não use a publicação para credenciais, informações internas confidenciais ou dados sensíveis de operação. Verifique a permissão de uso dos logos e imagens antes de tornar o repositório público.
